# openEuler 权威入口

openEuler 官网顶部导航包括：下载、开发、文档、学习、支持、社区、动态和源码。以下仅收录可用于版本、仓库、软件包、兼容性及技术事实调研的入口；课程、活动宣传和具体版本快捷链接不作为通用调研入口。

`https://www.openeuler.org` 当前重定向至开放原子基金会域名下的 openEuler 官网。引用资料时使用页面实际规范地址。

## 使用约束

- 优先使用与目标版本匹配的发行版、文档和仓库分支。
- 使用 `community` 元信息确认 SIG 归属和仓库列表；官网 SIG 页面只作为入口。
- AtomGit 官方仓库优先于 GitHub 镜像。
- 软件中心、Repo 源和镜像站证明资源可获取，不等同于软件默认安装或已验证运行。
- 新闻、博客和市场报告用于定位线索；技术结论仍需由源码、正式文档、公告或兼容性数据验证。
